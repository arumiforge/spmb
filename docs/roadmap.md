# Roadmap

Phases deliver in the school's priority order (brief §9). Each phase ends with
docs, guides, changelog and a demo on staging.

| Phase | Scope | Status |
| --- | --- | --- |
| 0 — Foundation | Repo layout, git rules, CI/CD workflows, agent skills, docs skeleton, `ai/` prompts, interview round 1 | done (PR #1) |
| 1 — Platform core | Frontend build (Tailwind v4 + Flowbite), layouts (admin full width, public, auth), breadcrumbs, settings + white label, module registry, auth + roles/permissions, optional 2FA, audit log, Panduan skeleton | **in review** (PR #2) — done: auth + roles, audit log, 2FA service and screens, installer, frontend build, layouts, settings + white label, user management, module registry/menu, Panduan skeleton; remaining: module on/off UI, audit log viewer |
| 2 — Registration | Waves, online + offline form, numbering, duplicate check, school reference data, document upload/resize/verification, PDF card + QR, status check, basic public pages | planned |
| 3 — Placement test | Test calendar, sessions/rooms/quotas, automatic allocation, QR/search attendance, rescheduling log | planned |
| 4 — Re-registration & reports | Re-registration, uniform status, dashboard stats, filters, XLSX/CSV/PDF export, XLSX import | planned |
| 5 — Engagement | Public site content and announcements, visitor analytics, interactive chat | planned |
| 6 — Launch | Server setup, backups + restore drill, security review, load test, role guides complete, staff training | planned |
| Later | WhatsApp notifications, uniform stock/packages, digital payment, trend analysis, integrations | backlog |

Target dates depend on when wave 1 opens (interview round 1, Q2).
